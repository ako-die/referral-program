# Referral Program

Prototype aplikasi pelaporan referral berbasis HTML/CSS/JavaScript.

## Fitur
- Splash screen
- Login User: Pejabat / Petugas
- Input Referral
- Penyimpanan data di browser (localStorage)
- Daily Report (khusus Pejabat)
- Cetak Laporan
- Share Laporan
- Hak akses Petugas vs Pejabat
- Responsive untuk HP

## Cara menjalankan
Buka `index.html` di browser. Untuk penggunaan seperti aplikasi Android/PWA, tahap berikutnya dapat ditambahkan manifest, service worker, database online, dan packaging APK.

Catatan: versi ini adalah prototype lokal. Data belum tersinkron antar-device/user.
